# Command Spammer - Fabric Mod 1.20.1

Мод для автоматической отправки списка команд в чат с настраиваемой задержкой.

## Использование
- Нажмите **P** в игре чтобы открыть меню
- Введите команды (по одной на строку) или вставьте из буфера обмена (Paste Clipbord) 
- Укажите задержку в тиках (20 тиков = 1 секунда)
- Нажмите **START**

## Установка
1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) для 1.20.1
2. Установите [Fabric API](https://modrinth.com/mod/fabric-api) для 1.20.1
3. Скачайте .jar 
4. Положите в папку `.minecraft/mods/`
